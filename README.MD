# KillerQueen

### ESP32-based Hexapod Robot — C++ / ESP-IDF / FreeRTOS

KillerQueen is a **6-legged robotic platform** developed as a personal embedded systems and robotics project.

The robot is controlled by an **ESP32** running **ESP-IDF** and **FreeRTOS**. Its firmware is written in C++ and is designed around modular abstractions for servomotors, legs and high-level motion control.

The project focuses on several embedded software topics:

* Real-time task management
* Hardware abstraction
* PWM servo control
* Bluetooth communication
* Inter-task communication
* Motion interpolation
* Embedded software architecture
* Hardware/software integration

> **Project status:** Work in progress.
